# 填空卡 · 期刊路线图 / 图形摘要

> 用法：复制下面这段，填满「」发过来。**版式不用描述**——画布、字号地板、配色、
> 图注格式由预设按 `journal-route-spec/references/scenarios.md` 的"期刊"一档决定。
> 只画**已经得到的**结果；未完成的一律不画（这是期刊图与标书图的根本区别）。

```
场景：期刊路线图 / 图形摘要
目标期刊：「Nature 系 / Cell 系 / Elsevier / 中文核心 / 未定」
栏宽：「双栏 180 mm / 单栏 85 mm / GA 120×60」
一句话结论：「这张图证明了什么」—— 不是"我们研究了什么"
分区：「4–8 个」，每区一句话结论：
  1「 」
  2「 」
  3「 」
  4「 」
箭头主线：「数据从哪流到哪」，一句话
要出现的图元：「病毒 / 细胞 / 小鼠 / 人群 / 分子 / 仪器」，估计各几个
数据是否真实：「有原始数据（贴表）/ 示意即可（我会在图注标 schematic）」
图注语言：「英文 / 中文」
```

## 我会默认这么做（不用你写）

- 画布 180×110（双栏）或 120×60（GA），字号地板 **5.0 pt**；
- 中文 KaiTi、英文 Cambria，PDF 字体全嵌入；
- 分区浅底 + 同色系标题带，语义色固定（改善=绿、恶化=红、中性=灰）；
- 图注 2–4 句：**结论 → 方法 → 缩写与 n → 数据来源**；
- 出 pptx + 600 dpi PNG + 矢量 PDF 三件套，附 `ATTRIBUTION.md`（用到的每个图元逐条记许可）。

## 反例（这样填一定返工）

- ❌ 给我 12 个分区 —— 期刊图装不下，我会合并到 8 个以内；
- ❌ "把没做完的也画上，显得完整" —— 期刊不接受，改投标书场景；
- ❌ 只给标题不给结论 —— 图形摘要的价值在结论，标题已有全文承担。
