# 提示词模板（照抄即可）

> 目标：让你一句到三句话就能拿到"能送审"的图，而不是来回改五轮。
> 关键不是描述**长相**，而是把**层级**和**每层的盒子内容**说清——外形我自己会排。

## 0. 最小可用（有参考图时，三行）

> 按 `nsfc-route` 画一张 A4 竖版技术路线图，构型用**树状汇流式**，层级和盒子内容照附件这张图。
> 中文 SimHei，盒内字号 ≥8 pt；先给我 4 行规格 + 箭头拓扑表，我确认后再画。
> 交付 pptx（可编辑）+ 600 dpi PNG + 矢量 PDF。

这三行已经够我开工。下面的模板只是在你**没有参考图**、或者想一次到位时用。

## 1. 标准模板（推荐，直接粘）

```
按 nsfc-route 技能画 A4 竖版（210×297 mm）技术路线图，构型 = 树状汇流式。

【项目】<题目>｜<面上/青年/重点>｜<学科口，如 感染科/内分泌/老年医学>
【科学问题】<一句话：什么临床现象解释不了>
【核心假说】<A → B → C，一句话>

【层级表】自上而下，[] 是并列盒子，→ 是串行
L0  [<入口，如 临床 XX 病例>]
L1  [<检测1>][<检测2>][<检测3>][<检测4>][<临床+影像判断>]      ← 5 个并列，扇出
L2  汇流结论：<一句话，把这 5 项和临床现象串起来>
L3  <机制研究>（朱红横条，居中，全图唯一深红）
L4  [体外细胞实验] ←→ [体内动物实验]                            ← 二次分叉
L5  左臂：[<干预1>][<干预2>][<干预3>]；[<提取/建模>]
L5  右臂：[<造模>] → [<分组>] → [<模型>]（虚线框）⇠ 虚线[<干预药>]
L6  左臂读数：[<检测A>][<检测B>][<检测C>]；中列信号：[Ca²⁺][<分子>][eNOS][NO/ROS][VCAM-1]
L6  右臂读数：[NETs 检测][内皮激活][免疫血栓][迁徙感染]
L7  结论①<左臂收口>；结论②<右臂收口>；结论③<干预效果>
底部  <总结论横条，一句话>

【硬要求】
- 字体 SimHei；标题 17 pt、模块 11 pt、盒内正文 ≥8 pt（压不下就砍字，不许缩字）
- 配色按证据来源：临床=浅粉、机制条=朱红、体外=蓝绿、体内=紫、读数=灰蓝、结论=浅黄；纯色平涂，禁渐变/阴影/3D
- 连接线走"竖干 + 横总线"正交折线；实线=主链、虚线=可选或干预；箭头不得穿字
- 图元 ≤8 个、均 ≥12 mm（人群、培养皿、中性粒细胞、小鼠、肝脏）
- 图内最多 1–2 张统计图（KM / ROC / 森林图），其余进正文
- 交付三件套 + 图注（写清示意值）

【流程】先给 4 行规格 + 箭头拓扑表 → 我确认 → 再出图
```

## 2. 只有图、不想写模板时的三句话

补这三点能省一轮返工：

1. **项目类型 + 学科口**：面上/青年、哪个临床口——决定评审期待（青年 3 个模块就够，重点要 5–6 个）。
2. **文字以谁为准**：图上的字要不要改（数字、组名、药名最容易涉及真实性）。
3. **要不要图元**：临床图里我默认 ≤8 个，多了会显得"没想清楚"。

## 3. 我会先回你什么（用来确认没跑偏）

不是图，是三张表：

```
规格（4 行）：画布 / 故事 / 分区 / 箭头
箭头拓扑表：ID | From | To | 线型 | 语义 | 优先级
层级表：L0…Ln，每层盒子清单与字数
```

三张表 30 秒能看完，比看一张画错的图快得多。

## 4. 验收清单（你照着看，8 条）

1. 一页放得下，**没跨页**；A4 打印后最小的字还能读。
2. 第一眼能找到**科学问题**（在 L0–L2）。
3. 每个盒子都能说出"它是**哪来的证据**"（临床/体外/体内/读数）。
4. 扇出—汇流的线是**正交**的，没有斜线穿过盒子。
5. 每条臂都有**自己的结论**，底部才有一条总结论。
6. 全图只有**一个**高饱和色，且给在"机制研究"或"创新点"上。
7. 灰度打印后层级仍分得开（把 PNG 转黑白自看）。
8. 图里的数字（n、浓度、时间）都能在正文找到出处。

## 5. 反例（这样说我容易跑偏）

| 你说 | 我会画成 | 更好地说 |
|---|---|---|
| "画个流程图" | 实验步骤流水账，没有科学问题 | "画技术路线图，入口是临床问题，出口是干预效果" |
| "照这张图画" | 只学到配色，学不到层级 | "照这张图的**层级**画，配色按我们的语义重排" |
| "字多一点没关系" | 字号被压到 6 pt，打印糊 | "宁可砍到 3 个盒子，也不要缩字号" |
| "再加几张统计图显得有数据" | 图变满、重点丢 | "只放 1 张关键统计图，其余进正文" |
| "做得炫一点" | 渐变 + 立体块 | "学术风：纯色平涂、留白、深色=一级" |

## 6. 什么时候**不要**用这个模板

- 只有 3 个模块、没有分支 → 用三段式（`archetypes.md` A），别硬套树形。
- 是期刊图形摘要 → 走 `tech-route-atlas`，横向 254×142.9，图元可以多。
- 只是想排版正文里的表格/图注 → 不需要本技能。
