# 五种构型（按项目类型选，别自创）

> 选型的唯一标准：**评审扫 10 秒后能不能说出"他在解决 X，分三步，成果是 Y"**。
> 下面每种都给了 A4 竖版 210×297 的骨架坐标（边距 12，内容宽 186），可直接抄。

## A. 三段式（问题 — 内容 — 成果）★ 面上 / 青年默认

最稳、评审最熟。上中下三段，中间 3 个研究内容纵向串行。

```
┌─────────────────────────────────────────┐
│ 题目（18–20 pt，1 行）                   │
│ 副标题：面上项目（2026–2029）· 技术路线图 │
├─────────────────────────────────────────┤
│ A 科学问题与工作假说                     │  28 mm
│  ┌ 前期基础 ┐→┌ 关键科学问题 ┐→┌ 工作假说 ┐│
├─────────────────────────────────────────┤
│ B 研究内容一（目标 / 关键技术 / 可验证产出）│  46 mm
│            ↓ 主干                        │
│ B 研究内容二                             │  46 mm
│            ↓                             │
│ B 研究内容三                             │  46 mm
├─────────────────────────────────────────┤
│ C 创新点（唯一强调色）                    │  18 mm
├─────────────────────────────────────────┤
│ D 预期成果（论文/专利/人才/转化 四栏）     │  28 mm
├─────────────────────────────────────────┤
│ E 风险与对策（3 组）                      │  24 mm
└─────────────────────────────────────────┘
```

纵坐标（实测可用）：`title 9.0/h11` `sub 21.0/h5` `A 28.5/h28` `B 60.5/h146`（3×48.67，gap 5）
`C 210.5/h18` `D 232.5/h28` `E 264/h24`；主干箭头 x=20.5，三段 y 区间 `(56.5,60.5)` `(109.2,114.2)` `(162.8,167.8)`。

适用：面上、青年、地区。模块数 3（青年）/ 3–4（面上）。

## B. 分栏式（左问题 — 中内容 — 右方法/产出）

适合内容横向关系强、或者要突出"方法学"的项目（社科、管理、部分医学交叉）。

```
┌────────┬─────────────────────┬──────────┐
│ 科学   │  研究内容一 ▸ 二 ▸ 三 │ 关键技术  │
│ 问题   │  （横向三步，等宽）   │ 与产出    │
│ 假说   │                      │ （纵列）  │
└────────┴─────────────────────┴──────────┘
   55 mm          90 mm            38 mm
```

注意：中间横向三步之间箭头要短（≤8 mm），且三步卡等高；右侧方法列用项目符号，不用第二套卡片。

## C. 顺序式 / 技术主线式（Pipeline）

适合"样品 → 处理 → 测序 → 分析 → 验证"这类技术链清晰的医药/材料项目。
**风险**：极易退化成实验流程图 —— 每一段必须写"科学问题怎么被回答"而不是"机器怎么跑"。

```
┌────────────────────────────────────┐
│ [1] 建模 ─→ [2] 干预 ─→ [3] 表型  │
│      ↓          ↓          ↓      │
│   产出1       产出2       产出3    │   ← 每段下方必须有产出条
└────────────────────────────────────┘
```

用 `cv.block_arrow()` 或 `cv.arrow` 连段，段与段之间留 6 mm；每段 3 行以内。

## D. 层进式 / 漏斗（重点、重点研发）

从"临床现象 → 人群 → 动物 → 细胞 → 分子"逐层收窄，宽度每层递减（`ladder(b, 4, step=8)`）。

```
████████████████  临床与人群
  ████████████    动物模型
    ██████        细胞与类器官
      ██          分子机制
```

青年项目**不要**用——内容量撑不起四层，会显得空。

## E. 矩阵式（内容 × 方法 / 内容 × 年度）

两个维度都重要时用（例如 3 个内容 × 3 类方法）。表头行 + 表头列，其余为对勾或关键词。

```
        转录组   蛋白组   代谢组
内容一    ●        ○        ●
内容二    ○        ●        ●
内容三    ●        ●        ○
```

● 主用 ○ 辅助。矩阵式的好处是"方法覆盖度"一眼可见，坏处是看不出因果链——所以**还要在左侧留一列箭头**表示内容间的递进。

## 不推荐（正文里别用）

| 构型 | 为什么别用 |
|---|---|
| 时间轴式 / 甘特图 | 年度安排属于正文"研究计划"，画成图会和正文重复，且评审会问"为什么没有逻辑关系" |
| 纯流程图（无问题、无产出） | 评审无法判断科学价值，直接当"技术员式本子" |
| 环形/循环图 | 国自然项目是有限期推进，闭环会让人误以为没有起点终点；机制循环放到"工作假说"小图里可以 |
| 3D / 渐变 / 阴影立体块 | 打印后发灰、显廉价，多条评审指南明确反对 |

## 组合建议

- 三段式（A）做**主骨架**，内部模块用顺序式（C）排列 → 最稳。
- 想在 A 里加"方法覆盖"，就把每张卡的"关键技术"栏做成小型矩阵（2 列 × 3 行）。
- 层进式（D）可以嵌进 A 的"研究内容一"，用来表达"人群→动物→细胞"的验证链。
