# 箭头：拓扑、线型、避让、图注

## 一、先拓扑，后画线

路线图的返工 80% 出在箭头。开工前把这张表写出来，用户确认后再动手；改图时**先核对表**，
再改坐标（顺序：箭头 → 布局 → 字号/配色）。

| ID | From | To | 线型 | 语义 | 优先级 |
|----|------|----|------|------|--------|
| A1 | Zone1 分组 | Zone2 时间轴 | 实线 1.1 pt | 同批动物进入追踪 | P0 |
| A2 | Zone6-3 | Zone6-4 | 实线 0.8 pt | 因果推进 | P1 |
| A3 | Zone6-4 | Zone6-2 | 虚线 4 mm 破折 | 反向调控 | P2 |

规则：
- **一条逻辑箭头 = 一个形状**。多段线段拼接会让虚线的 dash 在每个拐点重新起算，
  视觉上会"断开"；必须 `cv.route(pts)` 用 freeform 一次画完。
- 主流程实线 `S.bold 1.1`，次级 `S.base 0.8`，注解线 `S.hair 0.4`。
- 虚线只表达三类语义：反向调控 / 推测机制 / 数据流（非物理流）。
- 同类箭头线宽、箭头大小、颜色必须一致；颜色用 `p.ink3`（中性）或 `p.zone_line(acc)`（同区）。
- 箭头不表达"并列"。并列用对齐的卡片 + 无箭头。

## 二、坐标写法

```python
# 直线（自动留白 shrink 防止压到框线）
cv.arrow((a.x2 + 0.3, a.cy), (b.x - 0.3, b.cy), lw=S.bold)

# L 型（先横后竖 mode="hv"，先竖后横 "vh"）
cv.elbow((a.cy and a.x2, a.cy), (b.x, b.cy), mode="hv")

# 折线（一条 freeform，虚线才不会断）
cv.route([(fx, cards[3].cy), (fx + 0.9, cards[3].cy),
          (fx + 0.9, cards[1].cy), (fx, cards[1].cy)],
         colour=p.ink3, lw=S.hair, dash=4)

# 多源汇聚（三个源 → 一个目标）：三条 arrow 共用一个入点，入点前加 0.8 mm 直线缓冲
```

**锚点**：优先用 `box.anchor("right"|"left"|"top"|"bottom", frac=0.5)` 取边中点，
不要手写 `box.x + box.w` 之后又改宽度忘了同步。

## 三、避让

1. 箭头两端各留 0.2–0.4 mm，不要贴边（`arrow(..., shrink=0.3)` 或直接改坐标）。
2. 箭头不得穿过任何文字块。若必须跨越：绕行到卡片间隙（gap ≥ 2.2 mm 才够走线）。
3. 两条箭头相交时：主线连续，支线让路；无法让路就在交叉处加 0.6 mm 白色桥接
   （`cv.rect(Box(x-0.8, y-0.8, 1.6, 1.6), fill=p.paper, line=None)`）。
4. 箭头不要压分区标题带；分区内部的箭头止于内容区边界内 0.5 mm。
5. 长箭头（>40 mm）中间加 1 个 30% 透明度的三角形提示方向，或改成分段 + `chevron`。

## 四、箭头样式阶梯

| 场景 | 写法 |
|---|---|
| 主流程横向推进 | `cv.arrow(p1, p2, lw=S.bold, head="triangle")`; 或 `cv.block_arrow(b, "right")` |
| 阶段块（粗箭头带宽） | `cv.block_arrow(Box(...), "down", label="筛选")` |
| 阶段序列（V 形） | `cv.chevron(b, "步骤 2", acc=1)`，首尾用 `first/last` |
| 汇聚/分叉 | `cv.elbow` + 短直线，入点统一 |
| 双向互作 | 两端都设 `start="triangle"`：`cv.arrow(p1, p2, start="triangle")` |
| 抑制（⊥ 头） | `head="bar"`（或 `"none"` + 手画短横线，兼容性最好） |

## 五、图注

- 虚线、抑制头、双向箭头必须在总图注里有一句解释；图内不要放图例框。
- 若箭头有编号（A1/A2），图注写"箭头编号对应正文第 X 段"——期刊图注常见做法。
- 数量级/时间信息直接标在箭头旁（`size=5.2`，`colour=p.ink3`），例如 "33 月龄"、
  "n=100/组"。

## 六、自检清单

- [ ] 每条箭头都能在拓扑表里找到 ID；表里没有的不许出现
- [ ] 没有箭头穿过文字、图例、图标
- [ ] 虚线是**一条**形状（在 PPT 里点一下能整条选中）
- [ ] 同类箭头线宽/颜色一致
- [ ] 箭头尖端没有悬空（都落在卡片边或分区边上）
- [ ] 反向/推测类箭头有图注
