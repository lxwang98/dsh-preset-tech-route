# Custom schematic assets / 自定义示意素材

These assets were drawn from scratch on 2026-11-18 for the 7-panel reference replica.
They contain no measured data and carry no third-party licence obligations.

- `manhattan-plot.svg` — dense schematic Manhattan plot (chromosome-coloured points, 4/6 thresholds), CC0.
- `snp-manhattan-panel.svg` — SNP allele blocks above a dense Manhattan plot (the panel-5 composite), CC0.
- `gut-wall-epithelium.svg` — schematic intestinal epithelial wall (four cells, microvilli, tight junction, basement membrane), CC0.
- `human-male.svg`, `human-female.svg`, `human-child.svg` — flat cohort silhouettes, CC0.
- `dna-double-helix-blue.svg` — bold blue DNA double-helix icon, CC0.

`male`, `female`, `child`, `cohort`, `dna`, `helix`.
